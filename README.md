# Simple Python Netcat Utility

A basic networking tool written in Python to mimic functionality of the classic `nc` (Netcat) utility. It allows for simple TCP communication between two machines (or two terminal windows) in either **Server** or **Client** mode.

## Features
- **TCP Socket Communication**: Reliable data transfer.
- **Server Mode**: Listens for incoming connections.
- **Client Mode**: Connects to a listening server.
- **Cross-Platform**: Works on Linux, Windows, and macOS.

## Installation

This tool requires Python 3. No external libraries are needed.
